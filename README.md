# The Pool at Night

A liminal, scroll-driven web experience — the scroll is the swimming, and every section sinks you deeper.

Built with Vite 6, React 19, TypeScript, and Tailwind CSS 4, with animated caustics, film grain, drifting imagery, and an optional Web Audio ambient hum.

Best experienced with sound on, at night, in a quiet room.

Deploy: import the repo into Vercel — it auto-detects Vite (`npm run build` → `dist`).
